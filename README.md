**HTML · CSS · JavaScript · Firebase · Chart.js · Netlify**

Personal finance dashboard developed as a team project using agile methodology (Scrum and Kanban).

- Interactive charts and key indicators of spending
- Budget alerts with a traffic-light system and savings goals
- User accounts with cloud storage in Firebase Firestore
- Export of reports to PDF and Excel
- Deployed online with Netlify
